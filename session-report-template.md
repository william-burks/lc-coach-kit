Generate one of these at the end of every session. The voice coach produces it; you paste it to your text Claude for the code review + logging. Copy the block below per session.

```
Problem:        __ (LC #__)
Language:       __
Attempt #:      __
Time:           __ / 50-min cap
Mode:           TEACH / INTERVIEW

Outcome:        clean-solo / with-assist / partial / failed
Approach:       __

Key win:        __

Whiteboard:     solid __ | needed prompting __
Job-first:      clean / partial / inverted — phrase I used: __
Complexity call: clean / partial / wrong — what I said: __
Struggle points: __ (self-corrected vs needed a nudge)

Mantras to carry forward:
  1) __
  2) __
  3) __

Next rep:       __ (optimal version to write / cold run-back date: __)

Code review (text Claude fills this in):
  __
```

## Effort score (log every problem): 1 / 2 / 3
- **1** — low effort / distracted
- **2** — normal
- **3** — pushed past real resistance

## Grading honesty
"clean-solo" = solved cold, no hints, no help. If you needed a nudge, it's "with-assist" — say so. The spaced-repetition schedule depends on accurate grades; flattering yourself just hides the gap.
