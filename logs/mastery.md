# Mastery Ledger

Mastery is **computed from your logged outcomes — never from a coach's verbal
grade.** A problem becomes MASTERED only when the data earns it, so an inflated
"great session!" can't move it. This is the override on flattery.

Levels:
- **SHAKY** — not yet solved cold, or the last rep regressed (partial/failed/forgot).
- **LEARNING** — at least one clean-solo solve, but not yet proven under retention.
- **MASTERED** — ≥2 clean-solo reps, ≥1 of them a clean **INTERVIEW** rep (a real
  retention test, earned by hitting the spaced-rep date), and complexity correct.

`Cx` = complexity correct on the latest rep. `IV-clean` = clean-solo reps done in
INTERVIEW mode.
