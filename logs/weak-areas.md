# Weak Areas — the engine

This is the most important file in the kit. **Every repeated mistake goes here.** Flag a pattern when **3+ problems** hit the same issue — then next week adds 1–2 problems targeting it. This is what turns grinding into improvement.

Two levels: **pattern-level** (you're weak at a whole category, e.g. graphs) and **habit-level** (a recurring mistake across problems, e.g. you forget an include, you jump to code before planning).
