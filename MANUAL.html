LC Coach Kit — System Manual

An AI-coached LeetCode prep system: a voice coach for the thinking + the lc CLI for habit-aware review and honest logging.

OverviewInstallWorkflow ModesCommandsFiles SafetyArchitectureTroubleshooting

1 · Overview

Two tools, one loop:

  • The voice coach — a Claude app chat with voice-coach-brief.md uploaded, run in voice mode. Coaches your thinking (approach, complexity, edge cases). Does not write your code.
  • The lc CLI — a tiny local tool: a second, habit-aware code review and structured logging into your logs/ files.

Talking problems through aloud builds interview fluency; the review + honest logging keep you from fooling yourself, because verbal fluency hides real bugs.

3 · Workflow (per session)

  1. lc status — see what's due.
  2. lc arm "<problem>" --mode TEACH|INTERVIEW — builds a session pack (brief + problem + your history + a curated warm-up drawn from your gaps + weak-spots) and starts the timer. Upload the pack to your Claude voice session.
  3. Run the session aloud with the voice coach. Write your code in a bare editor.
  4. lc review — paste your code for a habit-aware second opinion. Loop (revise → re-review) until clean.
  5. lc log — paste your session report; it updates your logs (timer auto-stops).
  6. Weekly: lc gap — aggregate trends + next focus.

4 · The two modes

TEACH — learning/stuck. Complexity warm-up quiz first (curated from your tracked gaps), problem shown, Socratic nudges toward the insight.

Coach: Warm-up, from your tracked gaps: two-pointer dedup — where does the skip go? … N² + N log N dominates to? … Now: two-sum on a sorted array — state the job.
You: Two numbers summing to target… a hash map?
Coach: It's sorted — does that unlock something simpler? (nudges, never tells)

INTERVIEW — performing. Verbal delivery, restate-cap of 2, you stay blind, self-example → pseudocode → code, coach silent + probes only.

Coach: [reads the problem aloud once] You may ask me to restate it twice.
You: [invent an example, trace it, pseudocode aloud, then code]
Coach: Are you sure that handles all-duplicates? (probes — doesn't fix)

5 · Command reference

6 · The files

No database — markdown files are the store. The weak-areas file is the engine: every repeated mistake goes there; at 3+ strikes it's a flagged pattern and next week targets it.

FileRole
voice-coach-brief.mdThe brief you upload to the voice coach (fill the [YOUR WEAK SPOTS] placeholder)
logs/problem-tracker.mdChecklist — tick on a clean cold solve
logs/spaced-rep-queue.md+14d / +30d re-attempt schedule
logs/weak-areas.mdYour recurring mistakes — the engine
logs/habits.mdOptional daily tracking
config.md · gap-analysis-log.md · .sessionGenerated at runtime (gitignored)

7 · Safety & trust

  • Open source — ~400 readable lines, no hidden behavior.
  • The AI never executes anything — it returns text only; this code does the writes. No eval, no shell-out.
  • File access is hard-scoped — refuses any path outside the LC folder.
  • You approve every write — log shows a diff before saving; review never writes.
  • Your key is env-only — read from ANTHROPIC_API_KEY, never written to a file. No telemetry, no third-party servers.
